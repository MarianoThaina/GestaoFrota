# Documentação do projeto

Documentos de acompanhamento do desenvolvimento, para o time consultar sem
precisar navegar o código.

| Documento | O que traz |
|---|---|
| [estado-atual.md](estado-atual.md) | O que está implementado hoje em cada camada, a situação de cada user story e o que falta configurar para o projeto executar |
| [pendencias-do-modelo.md](pendencias-do-modelo.md) | Campos e entidades que as user stories pedem e ainda não estão no modelo, com sugestão para cada um |

O protótipo de telas está em [`../prototipo/`](../prototipo/).

---

## Como manter

Estes documentos refletem um momento do projeto. Quando algo mudar de estado,
vale atualizar a linha correspondente em vez de deixar o documento envelhecer —
documentação desatualizada atrapalha mais do que ajuda.

Sugestão de gatilhos para revisar:

- ao fechar uma sprint
- quando uma user story sair de "não iniciado"
- quando uma pendência do modelo for resolvida ou descartada
